# Pneumonia Detection from Chest X-Rays

A deep-learning clinical decision-support tool that classifies chest
X-rays into three categories:

1. **Pneumonia** (Lung Opacity)
2. **Normal**
3. **Not Normal / No Lung Opacity** — an abnormality present, but not
   pneumonia

Built as a Great Learning AIML capstone project. **This tool is a
screening aid, not a diagnostic device** — see Limitations below.

## Dataset

RSNA Pneumonia Detection Challenge dataset (chest X-rays in DICOM format).
Not included in this repository due to size — see `data/README.md` for how
to obtain it. The notebook expects `stage_2_train_labels.csv`,
`stage_2_detailed_class_info.csv`, and the `stage_2_train_images/` DICOM
folder.

## Model

Multiple architectures were trained and compared in the notebook
(`notebooks/final_pneumonia_detection.ipynb`): a from-scratch CNN, VGG16
and ResNet50 transfer learning (base, enhanced, and fine-tuned variants).
The best-performing model on held-out test data, selected primarily on
Pneumonia-class recall and macro-F1 (see the notebook's Model Comparison
and Best Model Selection sections), is serialized as `best_model.keras`.

### Getting the model

This repo does **not** ship a pretrained model file. To get one:

1. Run `notebooks/final_pneumonia_detection.ipynb` end-to-end (requires the
   dataset above and a GPU runtime — Colab or Kaggle recommended).
2. The notebook's Section 13/14 writes `best_model.keras` and
   `deployment_config.json`.
3. Copy both files into this repo's `model/` folder before running the app
   or building the Docker image.

## Running Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the URL Streamlit prints (typically `http://localhost:8501`).

## Running with Docker

```bash
docker build -t pneumonia-detection .
docker run -p 8501:8501 pneumonia-detection
```

Then open `http://localhost:8501`.

## Running on GitHub Codespaces

1. Push this repository to GitHub, with `model/best_model.keras` and
   `model/deployment_config.json` present (see "Getting the model" above).
2. Open the repo in a Codespace (**Code → Codespaces → Create codespace**).
3. In the Codespace terminal:
   ```bash
   pip install -r requirements.txt
   streamlit run app.py --server.port 8501
   ```
4. Codespaces will detect the forwarded port and prompt you to open it in
   the browser — accept the prompt, or open the **Ports** tab and click the
   forwarded URL for port 8501.
5. Upload a chest X-ray image in the browser UI to run inference.

The actual forwarded URL is assigned per-Codespace at runtime and is not
fixed — document your real URL here only after you've confirmed the app is
actually running, not in advance.

## Using the App

1. Upload a chest X-ray (`.dcm` — the format the model was trained on —
   or `.png`/`.jpg` if that's what you have).
2. The app preprocesses the image using the exact pipeline recorded in
   `deployment_config.json` (image size, grayscale/RGB, normalization
   scheme) — this must match what the selected model was trained with.
3. View the predicted class and the probability for all three classes.

## Limitations & Disclaimer

- This tool is a **screening/decision-support aid**, not a diagnostic
  device. It is not a substitute for evaluation by a qualified radiologist
  or physician.
- Model performance figures (accuracy, recall, F1) are specific to the
  RSNA dataset's imaging conditions and population; performance on X-rays
  from different equipment, patient populations, or acquisition protocols
  is not guaranteed and has not been validated here.
- The dataset is imbalanced (Pneumonia is the minority class at ~22.5% of
  patients pre-training) — see the notebook's EDA section for the full
  discussion of how this was addressed and what residual risk remains.
- No claims of clinical effectiveness are made beyond what is directly
  supported by the test-set results reported in the notebook and final
  report.
- Model outputs should be periodically monitored post-deployment, and the
  model should be retrained as new labeled data becomes available — see
  the final report's Business Recommendations section.
